# JavaScript DOM Manipulation

This project covers JavaScript DOM manipulation, including selecting elements, modifying styles, handling events, and making network requests with Fetch API.

## Files

- **0-script.js** - Updates header text color to red using `document.querySelector`
- **1-script.js** - Changes header color to red on button click
- **2-script.js** - Adds `red` class to header on button click
- **3-script.js** - Toggles header class between `red` and `green`
- **4-script.js** - Adds a new `li` element to a list on click
- **5-script.js** - Updates header text content on click
- **6-script.js** - Fetches a Star Wars character name from an API
- **7-script.js** - Fetches and lists all Star Wars movie titles
- **8-script.js** - Fetches and displays "hello" in French from an API
